# 📚 BookVerse

**BookVerse** is a Django-based Book Recommendation App that allows users to explore and discover books through a simple web interface.

## 🚀 Features

* Book recommendations
* Browse book details
* Django models and database
* HTML templates
* Django views and admin panel
* SQLite database
* Deployed on Render

## 🛠️ Technologies Used

* Python
* Django
* HTML/CSS
* SQLite
* Gunicorn
* Whitenoise
* Render

## 📁 Project Structure

```text
BookVerse/
├── manage.py
├── bookverse/
├── books/
├── templates/
├── db.sqlite3
├── requirements.txt
└── README.md
```

## ▶️ Run Locally

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
