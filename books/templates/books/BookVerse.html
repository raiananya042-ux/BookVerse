About BookVerse

BookVerse is a demo book-discovery app with a built-in sample dataset — no account, backend, or API key needed. Search matches titles, authors, genres, characters, and related keywords (so "money" finds finance books, "AI" finds tech books, and so on). All data is for demonstration only.

Sample recommendations for demo purposes — not live book data.
